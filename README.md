## 🚀 Sobre o projeto

O **Watt Vision** é uma plataforma de monitoramento energético industrial desenvolvida para facilitar a visualização e a interpretação de dados elétricos.

O front-end foi desenvolvido com **React + Vite**, oferecendo uma interface responsiva para desktop e mobile.

---

## 🛠️ Tecnologias

- React
- Vite
- JavaScript
- HTML5
- CSS3

---

## ⚙️ Funcionalidades

- Dashboard de monitoramento;
- Cadastro e gerenciamento de equipamentos;
- Visualização de medições elétricas;
- Monitoramento de alarmes;
- Acompanhamento da conectividade dos dispositivos;
- Relatórios de consumo energético;
- Comparação entre períodos;
- Filtros por local, setor, equipamento e período;
- Interface responsiva para desktop e mobile.
